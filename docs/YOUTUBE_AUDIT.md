# YouTube API Services – compliance checklist & draft answers

Form: https://support.google.com/youtube/contact/yt_api_form (Audit & Quota Extension).
Use it if uploads stay locked to private, or later for more quota.

## Checklist before submitting
- [ ] GCP project has only the YouTube Data API v3 enabled; OAuth consent screen is **In production**, with a privacy-policy URL and homepage (e.g. a GitHub Pages page for the repo).
- [ ] Only the scopes `youtube.upload` and `youtube.readonly`.
- [ ] Data is only uploaded to **your own channel**; no third-party user data, no storage of API data beyond 30 days (the dedupe log keeps only your own video IDs).
- [ ] Description contains the AI disclosure (AI voice, automated script). `containsSyntheticMedia` = true (config `upload.youtube.contains_synthetic_media`; synthetic voice + AI-assisted script disclosed). `madeForKids=false`.
- [ ] No misleading metadata, no spam (unique text per video, no reused titles), disclaimer "Not financial advice".
- [ ] Rights: music generated by the project, OFL fonts, mascot is your own, data sources attributed (CoinGecko, FRED).
- [ ] Screencast/screenshots: pipeline log, Telegram approval, published video.
- [ ] Repository link (public) as the implementation documentation.

## Draft answers (English)
**What does your API client do?**
"A private, single-channel automation that renders original short finance-news explainer videos (crypto, stocks, macro) with our own animated mascot and uploads them to our own YouTube channel via videos.insert. No end users other than the channel owner; no third-party YouTube data is collected, displayed or stored."

**Which API services/methods?** "videos.insert (upload), videos.list (status check of our own uploads). ≤10 uploads per day."

**How do users authenticate?** "Only the channel owner authorizes once via OAuth 2.0 (installed-app flow). The refresh token is stored as an encrypted GitHub Actions secret."

**Data retention?** "We store only the video IDs of our own uploads for de-duplication. No other API data is stored."

**Why more quota / why unlock public uploads?** "The upload volume fits the default quota (≤10/day). We request the audit so videos uploaded by our verified project can be published publicly. Every video is reviewed by a human via a Telegram approval step before upload (optional switch)."

**Content policy:** "Each video has unique script text built from live API data with at least two independent news sources per story; numbers come only from data APIs. The AI voice and automation are disclosed in every description. Music and artwork are generated by the project."
